## 🌟 نظرة عامة على المشروع (Project Overview)

منصة رقمية إنتاجية فائقة الفخامة متخصصة في تداول واستشارات العقارات الراقية في جمهورية مصر العربية (التجمع الخامس والقاهرة الجديدة، الشيخ زايد و6 أكتوبر، العاصمة الإدارية الجديدة، الساحل الشمالي ورأس الحكمة، والجونة).

تم تصميم المنصة وفق طراز العمارة المصرية الحديثة (Editorial Luxury Egyptian Real Estate) بألوان الهوية المعتمدة:
- **الأخضر الغابي (Forest Green):** `#193E32`
- **العاجي الدافئ (Warm Ivory):** `#F6F3EC`
- **الذهبي الرملي (Sand Gold):** `#B69A70`
- **الفحمي الراقي (Charcoal):** `#232A27`
- **الخط الطباعي:** الإسكندرية (Alexandria) بدعم كامل وتلقائي لاتجاه القراءة من اليمين إلى اليسار (Full RTL).

## 🛠 التقنيات المستخدمة (Tech Stack)

- **Next.js 14 (App Router):** بنية معمارية حديثة مع Server Components و Server Actions ومسارات ديناميكية.
- **TypeScript:** نمط فحص أنواع بيانات صارم ومتقدم لكافة النماذج والـ Schemas.
- **Tailwind CSS:** تصميم وتنسيق مرن مع نظام ألوان وظلال مخصص للفخامة (`shadow-luxury`).
- **Supabase Authentication (@supabase/ssr):** مصادقة متكاملة تعتمد على الجلسات الآمنة في الكوكيز (Cookie-based Sessions) وحماية المسارات.
- **Supabase PostgreSQL & Row Level Security (RLS):** حماية أمنية مشددة على مستوى الصفوف وقواعد الوصول لقاعدة البيانات.
- **Supabase Storage:** إدارة صور العقارات في وعاء التخزين `property-images`.
- **Lucide React:** أيقونات عصرية عالية الدقة.
- **Zod:** التحقق البرمجي الدقيق لبيانات نماذج المعاينة، الاستفسار، وإدراج العقارات.

## 🚀 خطوات التشغيل والتطوير المحلي (Getting Started)

### 1. تثبيت الحزم البرمجية
```bash
npm install
```

### 2. إعداد متغيرات البيئة (Environment Variables)
قم بنسخ ملف `.env.example` إلى `.env.local`:
```bash
cp .env.example .env.local
```

املأ القيم ببيانات مشروع Supabase الخاص بك:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your-supabase-publishable-key
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-publishable-key
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

> **ملاحظة هامة:** إذا لم تكن مفاتيح Supabase متوفرة لديك في الحال، تعمل المنصة تلقائياً في وضع **المحاكاة والعرض التوضيحي (Scaffolding Demo Mode)** بكفاءة 100% لكافة عمليات التصفح، الفلترة، المعاينات، وإدارة اللوحات!

### 3. تشغيل خادم التطوير
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

## 🗄️ إعداد قاعدة البيانات و Supabase (Database & Migrations)

تتضمن المنصة ملفات SQL جاهزة ومكتوبة بأفضل ممارسات الأمان في مسار `supabase/migrations/`:

### 1. تطبيق المخطط الأولي وقواعد الـ RLS:
قم بتشغيل محتوى الملف التالي في **Supabase SQL Editor**:
- `supabase/migrations/20261108000000_initial_schema.sql`

يقوم هذا الملف بإنشاء:
- جدول `profiles` مع Trigger تلقائي عند تسجيل أي مستخدم جديد في `auth.users`.
- جدول `properties` مع الحقول العقارية المصرية الفاخرة والفهارس السريعة (Indexes).
- جدول `property_images` لدعم المعارض المتعددة وترتيب العرض وتحديد الصورة الرئيسية.
- جدول `favorites` لحفظ تفضيلات كل مستخدم.
- جدول `inquiries` لتسجيل طلبات المعاينة والاستفسارات.
- سياسات الحماية على مستوى الصفوف (Row Level Security - RLS) التي تضمن:
  - القراءة العامة فقط للعقارات المنشورة (`status = 'published'`).
  - المستخدم يدير ويعدل عقاراته الخاصة فقط.
  - العقارات الجديدة تكون بحالة `pending` حتى يعتمدها المشرف.
  - المشرف فقط (`role = 'admin'`) يمكنه تعديل حالة الإعلانات ونشرها أو رفضها.
- إعداد وعاء التخزين `property-images` وسياسات رفع وتنزيل الملفات.

### 2. تطبيق بيانات النماذج الاستعراضية (Demo Seed Data):
قم بتشغيل ملف البذور في **Supabase SQL Editor**:
- `supabase/migrations/20261108000001_demo_seed.sql`

يقوم هذا الملف بإدراج عقارات افتراضية واقعية منتقاة في المربع الذهبي، بيفرلي هيلز، الزمالك، رأس الحكمة، الجونة، والعاصمة الإدارية.

## 🛡️ تعيين صلاحيات المشرف (Admin Setup)

لأسباب أمنية مشددة، لا يمكن لأي مستخدم ترقية نفسه لمشرف من الواجهة الأمامية. لترقية مستخدم إلى مدير نظام (Admin):

1. افتح **Supabase Dashboard** -> **Table Editor** -> جدول `profiles`.
2. ابحث عن حساب المستخدم المطلوب.
3. قم بتغيير قيمة الحقل `role` من `'user'` إلى `'admin'`.
4. أو عبر تشغيل الاستعلام السريع في SQL Editor:
```sql
UPDATE public.profiles
SET role = 'admin'
WHERE id = 'USER_UUID_HERE';
```

## 📦 النشر على بيئات الإنتاج (Production Deployment)

المنصة مُهيأة بالكامل للنشر بنقرة واحدة على منصة **Vercel** أو **Netlify**:

1. اربط مستودع Git بالمنصة.
2. أضف متغيرات البيئة التالية في إعدادات المشروع (Environment Variables):
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`
   - `NEXT_PUBLIC_SITE_URL`
3. أمر البناء: `npm run build`
4. مجلد المخرجات: `.next`
